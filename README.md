# E.Mal - Hello Kitty Web Apps 💖

Welcome to **E.Mal**, a collection of adorable Hello Kitty themed web applications!

## 🎀 Apps Included

### 🛍️ Pink Kitty Shop
A beautiful Hello Kitty merchandise store with shopping cart functionality.
- Browse cute products
- Add to cart
- Checkout experience
- **[Visit Shop](index.html)**

### 🕐 Hello Kitty Clock
World clock displaying time zones across the globe with real-time updates.
- 12 major world timezones
- Beautiful gradient design
- Time-of-day indicators
- **[View Clock](clock.html)**

### 😂 Joke Generator
Random joke generator with multiple categories to make you laugh!
- 4 joke categories (Any, General, Programming, Knock-Knock)
- Copy-to-clipboard functionality
- Joke counter
- **[Tell Jokes](joke-generator.html)**

### 📝 To-Do List
Organize your tasks with this beautiful to-do list app with local storage.
- Add, edit, and delete tasks
- Filter by status
- Automatic local storage saving
- Export your tasks
- **[Get Organized](todo-list.html)**

---

## ✨ Features

- 💖 **Hello Kitty Themed** - Cute pink design throughout all apps
- 📱 **Fully Responsive** - Works perfectly on mobile, tablet, and desktop
- ⚡ **Fast & Lightweight** - No downloads needed, runs in your browser
- 💾 **Local Storage** - Your data is saved locally on your device
- 🔐 **Secure** - No personal data sent to servers
- 🎨 **Beautiful UI** - Smooth animations and modern design

---

## 🚀 Getting Started

1. **Click on any app above** to start using it
2. **Your data is automatically saved** in your browser
3. **No account needed** - Just start using!
